# 蔡梵志 & 彭湘晴 婚禮 RSVP 表單題目清單

> 婚禮資訊：2027/3/27（六）午宴，台中蘭克斯特 Lancaster House（臺中市北屯區崇德路二段347號）。儀式 10:00 入場、10:30 開始；婚宴 11:30 入場、12:10 開席，儀式與婚宴分開，賓客可能只參加其一。

## 設計邏輯

參考多個台灣婚禮籌備網站與 Google 表單／SurveyCake 官方範本後，題目分三段：①身分與出席意願（含儀式／婚宴分開問，因兩者時間與性質不同、賓客可能只擇一參加，範本中即有此分開問法）②出席細節（人數、兒童、飲食，用於抓桌數與菜色）③聯絡與喜帖（寄送與後續聯繫）。凡標「[推論]」者為依本婚禮背景另外建議、非範本明確可見的題目，其餘標「[範本]」者在至少一個查得的範本中有直接對應題目。

## 題目清單

**Q1｜可以留下您的大名嗎？🌸（請填寫全名，會用來核對賓客名單與喜帖，也才認得出是哪位貴賓）**
- 題型：簡答
- 必填：是
- 設計理由：[範本] 姓名是所有查到的範本第一題，用於核對名單與喜帖印製（sunnyyubridal、marrizine 皆以此為 Q1）。

**Q2｜請問您是新郎／新娘哪一邊的親友呢？**
- 題型：單選
- 選項：男方（新郎）親友／女方（新娘）親友／雙方共同朋友
- 必填：是
- 設計理由：[範本] marrizine 範本 Q3「您是哪方人馬派來的？」、SurveyCake 官方範本強調「與新人的關係」是婚禮問卷必定出現的題目，用於安排座位與桌次分區。

**Q3｜請問您與新人的關係是？**
- 題型：單選
- 選項：朋友 / 同學 / 同事 / 親人 / 長輩朋友
- 必填：是

**Q4｜是否會參加 10:30 開始的證婚儀式？**
- 題型：單選
- 選項：會參加，準時到場見證／不參加儀式
- 必填：是
- 設計理由：[範本] sunnyyubridal 範本將「證婚儀式」與「午宴」拆成兩題分開問；本婚禮儀式（10:00 入場）與婚宴（11:30 入場）時間、性質皆不同，賓客可能只出席其一，因此沿用範本的分開問法而非合併。

**Q5｜是否會參加 12:10 開席的婚宴？**
- 題型：單選
- 選項：一定出席，我會準時到！／禮到人不到，仍請保留祝福／無法出席，獻上誠摯祝福
- 必填：是
- 設計理由：[範本] 對應 sunnyyubridal 範本 Q2「是否願意與我們共進午宴？」的三段式選項，禮到人不到的選項可另外標記喜帖／喜餅寄送對象。

**Q6｜出席婚宴的大人人數（不含兒童）**
- 題型：簡答（限數字）
- 必填：是（Q4 選擇出席才需填寫，建議表單用跳題邏輯僅在出席時顯示）
- 設計理由：[範本] sunnyyubridal 範本明確要求「當天出席人數（不含兒童椅人數）」，用於飯店抓桌數。

**Q7｜出席婚宴的兒童人數（6 歲以下）**
- 題型：簡答（限數字，無則填 0）
- 必填：是（Q4 選擇出席才需填寫）
- 設計理由：[推論] 範本原僅問「兒童座椅需求」未必分開統計兒童人數，本題依使用者背景要求「大人／兒童分開」而獨立成題，方便與 Q7 對應算兒童餐與座位。

**Q8｜是否需要兒童座椅或兒童餐？**
- 題型：單選
- 選項：不需要／需要兒童座椅／需要兒童餐／兒童座椅與兒童餐都需要
- 必填：否（Q6 填有兒童人數時建議必填，可用表單邏輯設定）
- 設計理由：[範本] sunnyyubridal、marrizine 皆有「是否需要兒童座椅與餐具」題目，是台灣婚宴會館常見的餐飲安排資訊。

**Q9｜本人用餐習慣（葷食／素食）**
- 題型：單選
- 選項：葷食皆可／全素（不含蛋奶）／蛋奶素／其他（請於下題說明）
- 必填：是（僅當 Q5 選擇「一定出席，我會準時到！」時才顯示並必填，比照 Q6/Q7/Q8 的條件顯示邏輯；Q5 選其他選項時此題隱藏且非必填）
- 設計理由：[範本] marrizine Q6「請問吃菜吃肉？」、jenwed 與 sunnyyubridal 都將葷素列為出席後必問題目，直接影響桌菜與素食桌數安排。條件顯示是因為不出席婚宴者無需被詢問用餐習慣，避免造成不必要的填答負擔。

**Q10｜同行者用餐習慣（葷食／素食）**
- 題型：單選
- 選項：葷食皆可／全素（不含蛋奶）／蛋奶素／其他（請於下題說明）
- 必填：是（僅當 Q5 選擇「一定出席，我會準時到！」且Q6人數大於1人，才顯示並必填；Q5 選其他選項或 Q6 人數 ≤1 時此題隱藏且非必填）
- 設計理由：[範本] marrizine Q6「請問吃菜吃肉？」、jenwed 與 sunnyyubridal 都將葷素列為出席後必問題目，直接影響桌菜與素食桌數安排。條件顯示是因為不出席婚宴者無需被詢問用餐習慣，避免造成不必要的填答負擔。

**Q11｜有特殊飲食禁忌或過敏食材嗎？**
- 題型：簡答
- 選項：（開放填寫，例：不吃牛肉、對海鮮過敏）
- 必填：否（僅當 Q5 選擇「一定出席」時才顯示，並選填）
- 設計理由：[推論] 查詢結果提及新人可加入「過敏食材」欄位供飯店挑選菜色時避開，屬常見建議但非固定範本題目，故列為推論加入、選填以免造成填答負擔。

**Q12｜喜帖需要寄送嗎？**
- 題型：單選
- 選項：想收到紙本喜帖，請寄給我／請寄電子喜帖給我（環保愛地球）／不需要，我都知道婚禮資訊
- 必填：是
- 設計理由：[範本] sunnyyubridal Q5、marrizine Q7、cardbyash 均以此題決定後續是否需要收集地址，是喜帖印製數量與寄送名單的關鍵題。

**Q13｜喜帖寄送地址**
- 題型：簡答
- 必填：是（僅當 Q10 選擇「紙本喜帖」時才需要填寫，建議設定條件顯示）
- 設計理由：[範本] sunnyyubridal Q6、cardbyash「喜帖收件地址」皆有此題，且註明僅需紙本喜帖者填寫。
- 新增：格式檢查僅做寬鬆長度檢查（trim 後少於 6 個字元視為疑似漏填，提示補齊），不用嚴格 regex，因台灣地址寫法差異很大，避免誤擋合法地址。

**Q14｜您的手機號碼**
- 題型：簡答
- 必填：是
- 設計理由：[範本] sunnyyubridal Q4、marrizine Q8 皆列為必填聯絡方式，供新人於人數異動或當天聯繫使用。
- 新增：手機格式檢查 09 開頭 10 碼（`^09\d{8}$`），送出前會先去除輸入中的空白與連字號再比對與送出，讓試算表資料格式一致。

**Q15｜Email（方便通知婚禮相關訊息）**
- 題型：簡答
- 必填：是
- 設計理由：Email 部分為 [範本]（sunnyyubridal Q7 單獨問 Email）；LINE ID 為 [推論] 加入，依使用者背景「聯絡方式含 LINE」的要求補充，因搜尋範本中未見以 LINE ID 為固定欄位，僅在部分新人自建表單中以文字提及聯絡方式含 LINE。
- 新增：Email 格式僅在輸入值含 `@` 時才檢查（避免誤擋合法 LINE ID），不含 `@` 一律視為 LINE ID 或留空、不驗證。

**Q16｜是否需要開車前來？**
- 題型：單選
- 選項：不開車／開車前來
- 必填：是
- 補充說明：當日備有酒水，若要飲酒請大家多搭乘大眾運輸工具或共乘❤️，另停車資訊見下方說明（幫我調整成溫馨俏皮口吻）
- 設計理由：[推論] 多次搜尋「婚禮表單 停車」均查無明確範本佐證此為常見固定題目，屬本次依蘭克斯特場地為獨棟會館、賓客可能開車前往北屯區的實務考量而建議加入的加值題，新人可視場地實際車位狀況決定是否保留。

**Q17｜想對我們說的話（祝福留言）**
- 題型：簡答（多行文字）
- 必填：否
- 補充說明：也要調整成溫馨口吻
- 設計理由：[範本] sunnyyubridal Q9「我想說．．．」、marrizine Q9 皆以開放式留言作收尾題，增加表單溫度。

## 加映題：🍡 花好月圓小投票

新人自己提出的趣味構想，**不列入正式 Q1~Q17 編號**（不佔用題號、也不影響既有欄位命名），單選、選填。

- 題目：🍡 花好月圓小投票｜您想吃哪一種內餡？
- 選項：黃色＆紫色地瓜／紅白小湯圓
- 顯示邏輯：當 Q5 選擇「一定出席，我會準時到！」時才顯示，只有出席午宴的賓客需要投票
- 必填：否
- 玩法：得票最高的口味，將成為婚宴當天實際的甜點菜單
- 對應欄位名稱：`q_dessert_vote`（前端 name 屬性，後端試算表欄位「花好月圓投票」）

## 未納入的題目與原因

- **喜餅是否需要／領取方式**：搜尋僅查到「不辦婚宴、只發喜餅」情境下才會用表單詢問喜餅領取意願的討論（多見於 Dcard 論壇），未查到「有實際午宴」的範本將喜餅列為表單固定題目；本婚禮已有午宴，喜餅可依出席人數統一準備並於現場以桌次核對，故未列入表單，如新人仍想追蹤可自行加題。
